# Frogger Game (Python Turtle)

## Author
Sylvester Doe

## Description
This is a simple Frogger-style game made with Python using the turtle module. The player moves a turtle across the screen while avoiding cars that move across the road. If the player hits a car, they reset back to the start. The goal is to reach the top of the screen.

## Reflection
This project took a long time to finish and was frustrating at times because I kept running into errors and things not working the way I expected. I had to fix a lot of small issues step by step. In the end, I learned more about how different Python files work together and how to debug problems instead of giving up.
